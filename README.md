# 🚀 PCS Media Website & Marketing Funnel

A modern, responsive, and high-converting landing page built for **PCS Media**, focusing on performance marketing and lead generation funnels.

---

## 🌟 Key Features

- **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.
- **Performance Marketing Layout:** Structured funnel design to drive user engagement and conversions.
- **Clean UI & Modern Styling:** Built with lightweight CSS for fast loading speeds.
- **Interactive Elements:** Smooth navigation and interactive UI elements powered by JavaScript.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Custom styling, Flexbox/Grid layouts, and responsive design.
- **JavaScript (ES6+):** Client-side interactivity and logic.
